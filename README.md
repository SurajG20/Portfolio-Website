# Suraj Goswami — Portfolio

**Problem → proof:** This site is the narrative layer for my GitHub — production outcomes (payments, GraphRAG, real-time) that do not live in public repos.

🔗 **Live**: [surajgoswami.vercel.app](https://surajgoswami.vercel.app)

## Approach

- **Astro** for fast static delivery and content sections.
- **React islands** for interactive project visuals and motion (Framer Motion).
- **Tailwind CSS v4** for layout and typography.
- Deployed on **Vercel** with resume PDF and project deep links.

## Tech

Astro · React · Tailwind CSS v4 · Framer Motion · Vercel

## Demo

```bash
bun install
bun run dev
bun run build
bun run preview
```
